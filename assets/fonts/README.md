# Fonts

- `fh-serif-*.woff2`: Source Serif 4 (variable, v4.005) by Adobe
- `fh-sans-roman.woff2`: Source Sans 3 (variable, v3.052) by Adobe

Both come from Adobe’s official npm packages (`source-serif`, `source-sans`). They’re subset to Latin characters to keep the files small. The full files include old-style numerals and small caps, which Google Fonts strips out.

The SIL Open Font License reserves the name “Source” for unmodified fonts, so the subset files are renamed “FH Serif” and “FH Sans.” The license files sit alongside them.
